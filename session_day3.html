PART 2　GAS と API の仕組み

Google Apps Script（GAS）は、スプレッドシートや Gmail を、決まった手順どおりに動かすプログラムです。

1　ブラウザだけで書ける

PC に何も入れません

2　無料で使える

個人の Gmail でそのまま使えます

3　PC を閉じても動く

Google のサーバーの上で動きます

Apps Script の画面。スプレッドシートの「拡張機能」→「Apps Script」で開き、コードを貼って「実行」や「デプロイ」で動かします
話すこと　Excel のマクロに近いもの。違いは3つ。PC に何も入れなくていい、無料、Google のサーバーで動くので PC を閉じていても動ける。 プログラムを書けなくていい。今日は、AI に書いてもらったコードを「どこに貼って、どう動かすか」がわかれば十分。 会社の Google Workspace の場合は、管理者の設定で止められていることがある。今日は個人の Gmail で進める。
PART 2　GAS と API の仕組み

GAS は、きっかけがあると動き出します

演習　3　キーをしまう

キーを、スクリプト プロパティにしまう

コードは「GEMINI_API_KEY」という名前の場所からキーを読みます。キーは ChatGPT には貼りません。

  1. Apps Script の左の歯車「プロジェクトの設定」を押す
  2. いちばん下の「スクリプト プロパティを追加」を押す
  3. プロパティに GEMINI_API_KEY と入れる
  4. 値に、コピーしたキーを貼る
  5. 「スクリプト プロパティを保存」を押す
「プロジェクトの設定」のいちばん下（値は見本の文字）
プロパティの名前は、大文字と下線まで同じに入れます。1文字違うと、キーが読めません。
見て回る　よくある間違いは、名前の打ち間違い（GEMINI_APIKEY など）と、キーの前後に空白が入ること。 ChatGPT が「ここにキーを貼って」とコードの中を指したら、それは使わない。キーはスクリプト プロパティだけ。 スクリプト プロパティは、この Apps Script の中だけの置き場。新しい Apps Script では、もう一度しまう（Part 4 のカテゴリ3・カテゴリ4 で出てくる）。 ここで入れたキーは、スプレッドシートを「編集者」で共有した相手には見える。共有するときは「閲覧者」にする。

演習　4　置く

ウェブアプリとして公開して、デスクトップに置く

公開すると URL ができます。Chrome でウィンドウとして開けば、デスクトップに置いておけるアプリになります。

公開する
  1. 右上の「デプロイ」→「新しいデプロイ」
  2. 歯車 →「ウェブアプリ」。実行は自分、アクセスは自分のみ
  3. 「デプロイ」を押して、出てきた URL を開く
デスクトップに置く
  1. Chrome の「︙」→「キャスト、保存、共有」→「ショートカットを作成」
  2. 「ウィンドウとして開く」に印をつけて作成
話すこと　「自分のみ」にしておけば、URL を知られても他の人は開けない。人に使ってもらう公開は第4回で。 位置情報を聞かれたら、許可してもしなくてもいい。許可しないと東京の天気になるように頼んである。 【推測】GAS のウェブアプリの中から位置情報が取れるかは未確認。確かめ方：講師の PC で開いて、天気の場所が今いる所になるかを見る。 【当日確認】Chrome のメニューの名前（「キャスト、保存、共有」「ショートカットを作成」）は版によって違う。講師の Chrome で確かめる。 コードを直したあとは「デプロイを管理」→ 鉛筆 →「新しいバージョン」で更新しないと、URL のページは変わらない（Part 4 でよく詰まる所）。
PART 3　AI と1つ作る

API キーは合言葉　守り方は4つ

キーを知っている人は、あなたの名前で AI を使えます。有料の枠なら、あなたに請求が来ます。

1　人に渡さない

チャット、メール、画面共有に出さない。講師にも見せなくて大丈夫です

2　コードやセルに書かない

今日のように、スクリプト プロパティにしまい、コードはそこから読みます。ChatGPT にも貼りません

# AI に直してもらう
$ claude
> ひとことを30字までにして
# Google に戻す
$ clasp push
